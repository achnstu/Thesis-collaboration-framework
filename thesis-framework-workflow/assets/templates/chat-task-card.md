# 对话任务卡

本卡是可编辑任务说明，填真实信息。跨对话发送需用户明确授权。

小任务可直接在任务消息中说明，不要求创建本文件。只交付该任务所需上下文，不把全部工程历史分发给每个执行者。

| 项目 | 内容 |
|---|---|
| 负责对话或人员、任务状态 | 待填写 |
| 主责模块与执行入口 | 写作／证据／文献／图表／文档／返修／框架／协调，填写实际模块路径 |
| 对应章节和研究问题 | 待填写 |
| 与全文主线、前后章节的关系 | 待填写 |
| 已确认的作者决定和相关经验 | 来源、日期、有效范围 |
| 必读文件和当前版本 | 只列必要材料，路径、版本或必要时哈希、具体位置 |
| 数据与证据 | 数据源、字段、样本、筛选、统计及限制 |
| 依赖任务及负责人 | 待填写 |
| 输入只读范围、允许写入的文件 | 待填写，每个共享文件指定唯一写入负责人，其他执行者交付独立候选 |
| 交付物及保存位置 | 待填写 |
| 验证与完成条件 | 本模块的一轮定向检查，文字按技能协议集中复查，注明实际范围及影响交付的待核项，不要求无关全量检查 |
| 接收方与交接方式 | 待填写，消息发送依平台权限执行 |
