# 写作任务提示词

这些是本框架的执行模板，按已读的现行材料填入【】内容，未知事实不猜填。执行依据为 [写作与证据](../../references/writing.md#参考引导写作与论证重构) 和 [一次反向复查](../../references/writing-review.md)。提示词帮助形成实际文字，不替代当前用户要求或作者确认稿，也不扩大写回、检索、实验及代理授权。

## 段落或章节起草

```text
按论文框架写作模块起草【目标部分】，范围为【指定位置】，使用【现行材料与证据】，交付【正文/前后对照/指定文件候选】。
先确定本节要回答的问题、各段职责、证据和前后承接，再写出实际候选。研究论证中分清主比较、解释性分析和适用范围，保留影响判断的条件、反例及取舍。
需要参考引导时，读取内嵌 Followwriting，从实际读过的参考全文中选取有用写法。没有参考全文时依据本研究材料独立起草，不声称完成对标。
按作者现稿的中文或英文约定处理表达、缩写、完整符号和引文归属。已有准确文字可保留，缺少结果或来源的位置不补造。
完成后按框架做一轮定向复查，修正后只复核受影响处。只要求正文时仅交正文，未授权不写回文件。
```

## 参考引导的实质改写或逐段对标

```text
按论文框架与内嵌 PaperSpine Followwriting 改写【原文位置】，参考【真实全文及版本】，保留【作者明确保护的内容】，交付【指定形式】。
先用本研究的问题与证据确定段落职责，再为参考分配实际有用的作用，例如交代缺口、解释方法、安排结果或展开讨论。借鉴结构和论证动作，形成独立表述。
落笔前在已有提纲或记录中简要确定“当前问题—拟采用的动作—本研究证据—预期成稿效果”，再写实际候选，不只交诊断或写作计划。
数据、条件、符号、文献归属及结论强度由当前稿和本研究证据决定。按作者语言约定改善表达，不模仿参考作者的个人声音，不强制逐段换来源或重写清楚段落。
按任务需要保留紧凑对照，引用实际页段定位，检查终稿是否真正完成所称借鉴动作。未发生借鉴的句子可无锚点。只要正文时不额外附写作台账。
在同一轮复查中检查论证、事实和来源，按已有代理授权执行，不另建写作代理或重复全文审查。
```

## 逐句前后与参考对照

```text
对【指定原文范围】执行逐句对照，使用【本研究证据】和【实际可用参考全文】，保持【作者当前语言与符号约定】。
先确认整段职责，再覆盖指定范围内每一句，包括未改句和本研究特有句。准确原句可以保留，无需为显示改动量改写。
每行写明原句位置与完整原句、完整终句、句子功能及具体修改理由、本研究证据、参考版本和页段位置、实际借鉴动作。没有参考对应时明确无锚点，新句没有原句就如实标明。一句拆分或多句合并需保留真实映射。
参考用必要的短摘录或精确转述，不虚构页码、原句或一一对应，不把参考结果迁为本研究结论。借鉴记录须能从终稿中核实。
交付用户要求的完整对照和实际候选文字，合并进行本轮文字复查，不顺带重跑实验、改未授权稿件或启动网页。
```

## 章节或全文论证重构

```text
按作者授权重构【指定章节/全文】，以【作者指定当前稿】及【证据与参考】为依据，保护【数据、公式、图表、对象及其他保留项】，交付【指定形式或新候选位置】。
先从真实材料提出可由现有证据支持的研究主线，区分主比较、解释分析、范围测试和补充诊断。最近增补实验或单个有利结果不无依据地改变研究身份。
检查授权范围内各部分是否让读者看清“比较对象—条件—指标—观察—推论”。必要条件放在首次需要的位置，讨论综合解释与文献关系，不重列整套结果或隐藏重要反例。
按段落职责选择互补参考，完成实际改写，再按作者语言和符号约定整合。原有可用结构与清楚段落保留，重大调整说明其具体作用，不套用单篇参考的特殊顺序。
在同一轮复查中先从成稿恢复论证，再对照原文、证据和借鉴记录。核心主张变化时核查受影响的标题、摘要与结论，未授权文件只列同步位置，不自动覆盖或增加新实验。
```
