# 第2章数据与阶梯定义

源 CSV 目录：论文根 `数据表/第2章_原理与建模/绘图CSV`。

## C2-D01 / D02

读取同定位号的 `绘图负载时序宽表.csv`。时间单位 s，负载 W/1000 转 kW。训练 Voyage 001–008，测试 Voyage 009–012。现有图 y=0–9 kW、间隔1，各面板 x 从0止于自身末个有效时间，不能统一到最长航程或凑整上限。

只画有限配对。已有源表只有尾部空白，若出现内部缺测，应分段画线，不能直接压掉缺测后把两端连接。现有脚本会对内部缺测报错，需先适配分段再交付。

## C2-D03

只读两份宽表的 `训练集_航程等权_`、`测试集_航程等权_` 列，保留采样点等权列在原表副本中但不画。不要把四种加权方式全画上去。

- 训练各航程 1/8，测试各航程 1/4，航程内样本或真实相邻增量等权。
- 左：`C2-D03 绘图负载持续宽表.csv`，x `原始总负载` /1000，y `持续比例`。
- 右：`C2-D03 绘图增量ECDF宽表.csv`，x `真实相邻负载绝对增量` /1000，y `经验累计概率`。
- 两份表已经算好统计，不重算差分。上游增量只来自单航程内相邻有限对，N点至多N−1增量，不跨航程、不补首点零。
- 左是 `P(load>=x)*100`，左连续。右是 `P(abs(delta load)<=x)`，右连续。
- 训练 `F(0)=0.417714046287124`，测试 `F(0)=0.251163451976669`，零处跳跃必须保留，不能画成从0平滑爬升。
- 训练负载约 −1e−15 W 的浮点值保留，横轴从0作显示，不改源值。

显示辅助节点由 `C2_D03.step_nodes` 实现，另存 Origin 辅助列，原支持点与两份原始宽表仍保留。

右连续 post 阶梯：`xs=repeat(x,2)[1:]`、`ys=repeat(y,2)[:-1]`。ECDF先补定义节点 `(0,0)`，末尾补 `(xmax,1)`。

持续曲线如最小支持点>0，先补定义节点 `(0,100)`。末尾补 `(原最大支持点,0),(xmax,0)`。将节点倒序后生成 post 阶梯，再反回，即得到左连续阶梯。端点延伸来自分布定义，不是新增观测。

验证每一段必须水平或垂直，用相邻支持点间的中点核查整个区间概率，另查零增量跳跃。这能识别阶梯方向颠倒，单纯单调性检查不足。

左轴0–9 kW、0–100%，右轴0–7.5 kW、0–1，这是当前完整数据支持上界向上取整。尾部虽稀疏仍要保留，不能为了曲线分开而裁掉长尾或截去概率0–0.8。
