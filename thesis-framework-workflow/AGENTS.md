# Project Rules

Follow the current host and enclosing project rules when present, and this package's root SKILL.md. No original-author global rule file or home directory is required. Embedded instructions are subordinate to the current user request and package routing. Keep paths relative, use synthetic examples, and exclude private identifiers from shared instructions and diagnostics.

Select the active module in SKILL.md and load only its required resources. Apply confirmed author requirements during execution, then check the actual output against inputs and the module's completion criteria. Use one focused review; after a correction, recheck only affected items. Do not add unrelated scans, reports, agents, or disclaimers. Parallel work requires clear dependencies and one writer per shared artifact.

For paragraph or batch writing, use the one read-only reviewer authorized by this workflow, following references/writing-review.md. Do not duplicate the same full review in the main agent or delegate recursively. Tiny edits, review-only tasks, user prohibitions, and unavailable delegation use a focused self-review instead.
