# 阶段实施与交接

按用户任务选择阶段。下列状态用于明确依赖和检查范围，不代表所有工作必须串行，图表和正文可在证据确定后并行准备。若只处理局部，检查受影响的相邻环节即可。

阶段表是内部工作参考，不要求作者逐项填写或批准。AI 按变化范围和风险完成必要核验，已有有效证据可复用，仅在新变更、冲突或未解决问题涉及该证据时重查。适合共同判断的图意、论证及表达，通过 [作者与 AI 共同审阅](collaborative-review.md) 结合实际成果讨论，避免将审查变成繁琐的多轮确认。

| 阶段 | 输入与主要工作 | 形成的材料 | 进入下一步前检查 |
|---|---|---|---|
| 资料接收 | 用户目标、现有稿件、学校要求、研究材料与文献，确认当前版本及任务范围 | 来源和版本清单、工作区入口、缺口 | 已有主稿与来源可定位，无稿件或未取得的材料明确标记 |
| 研究定位 | 识别问题、方法、贡献、对照与范围，整理导师意见 | 论点—证据映射、待确认事项 | 每项拟议贡献有对应材料，计划与完成分开 |
| 章节规划 | 规划全篇和章节职责、章节间承接、图表和公式落位 | 目录、章节素材表、初步图表规划 | 现有结构遵守作者决定，缺证据项标明，图表不以数量为目标 |
| 数据与图表准备 | 核对来源、比较条件、字段、聚合、单位和失败信息，设计图表 | 数据索引、派生表、图表记录、复现代码 | 指标能从源头复算，图型与统计含义一致，不完整数据明确标记 |
| 逐章写作 | 围绕问题、方法、结果及讨论写作，核对文献、符号和图文引用 | 章节底稿、引用依据、修改记录 | 每条结论可定位证据，章节衔接清楚，保留关键限制 |
| 文档装配 | 在用户指定文稿中插入内容，处理公式、引用、图表和样式 | 可编辑稿件、输入快照、对象基线 | 核对编辑范围和对象，图号、公式及参考文献对应 |
| 综合验收 | 复算核心数字，检查文献、结构、页面及输入输出 | 验收结果、问题清单和范围说明 | 区分自动检查、目视检查及未检查，不能用一个结果替代另一项 |
| 阶段交付 | 确认当前成果、路径、版本和未决项 | 交接记录及可恢复成果 | 文件存在可读，依赖、待办及下一负责人明确 |

遇到证据缺失、版本冲突或实验条件不可比，先记录影响位置和待核实项，独立部分继续。未完成的阶段不写成通过，作者已确认的决定与人工修改优先保留。

## 验收重点

- **工作区**：入口指向当前主稿，资料索引可定位，副本和原始来源关系清楚。仅检查当前任务相关材料。
- **结构与写作**：章节问题和前后承接明确，正文区分事实、推断与展望，不堆砌图表或套话。每项结果标清对象和条件。
- **证据与计算**：检查独立样本单位、缺测、失败、汇总层级、比较方向、单位和百分比分母。变更后核查正文、图表、摘要与结论。
- **图文与公式**：检查图表 ID 到正式编号的映射、图内图外术语、公式编号和符号定义。图形需真实回开和查看，Word 中的插图另验。
- **文献与格式**：文献内容确实支持引用句，元数据和引用域与文末条目一致。学校规范、分页与实际显示按适用范围检查。
- **交接**：使用 [交接模板](../assets/templates/handoff.md) 记录输入输出、已完成、实际验证和未解决事项。说明外部依赖，不把未来计划标为已完成。
