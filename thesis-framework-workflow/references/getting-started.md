# 首次使用与学科适配

适用于首次接触此工作流的作者或执行者。技能用于根据已有材料规划、写作和核验，不能替代作者确定研究问题，也不自动产生实验、文献或事实。

## 从哪里开始

先读取用户指明的文件和目标，并确认适用的项目规则。整理以下信息，只询问会改变当前任务结果且无法从材料推断的缺项：

| 信息 | 说明 |
|---|---|
| 当前任务 | 例如建立目录、规划整篇、写一节、核查结果、制作一图或排版 |
| 研究场景 | 学科、学位或文稿类型、主题、语言及目标读者 |
| 已有材料 | 当前稿、导师意见、学校规范、研究资料和版本，允许其中部分尚不存在 |
| 交付要求 | 输出格式、保存位置、目标章节、是否修改现有文件 |
| 实际边界 | 可用工具、数据权限、截止时间，以及已确认的作者偏好 |

能根据现有材料合理决定的事项直接处理，并写明关键假设。没有主稿时标记“尚无主稿”，从研究目标与现有资料开始。没有学校模板时先按内容结构工作，具体排版要求留待确认。材料不完整时先完成不依赖缺失资料的部分。

## 按任务选择

| 用户任务 | 先读 | 最小可交付结果 |
|---|---|---|
| 建立或整理工作区 | [工作区架构](workspace-architecture.md) | 实际目录或现有目录映射、入口和材料清单，记录未获得资料 |
| 确定全文框架 | [写作与证据](writing.md)、[阶段实施](stage-gates.md) | 研究问题、章节职责、证据映射和待确认缺口 |
| 按框架协调多个任务 | [协作与证据理解](multi-chat-collaboration.md) | 可供作者阅读的章节分工、证据入口、任务状态和交接 |
| 只写或修改一节 | [中文表达](chinese-academic-style.md) 或目标语言规范 | 指定范围内的文本、来源及需保留的条件 |
| 做文献综述或补引 | [文献工作流](literature.md) | 文献与论点对应表，注明是否读到原文 |
| 制作或核查图表 | [作图与验收](figures.md) | 图表记录、实际输出和已执行的核验 |
| 装配或排版 | [Word 与排版](layout.md)，若为 LaTeX 则按目标模板和编译工具检查 | 指定格式的成果、验证结果及未检查项 |

“论点—证据映射”是把每个主张连接到支持它的资料及具体位置。“图表定位号”是独立于最终图号的稳定材料编号。“阶段验收”是记录检查是否实际完成，不是要求用户逐步批准。

## 不同学科如何调整

- 定量实验或算法：明确样本、对照、重复单位、处理过程、统计口径及数据完整性，保留原始输入和计算脚本。
- 定性访谈、案例或田野：记录材料来源、采集与分析方法、编码或选例依据、解释过程及参与者隐私。没有图表或数值也可建立证据链。
- 人文或理论研究：记录原典版本、页码、译本、概念定义、解释路径及不同观点，不强套基线、实验指标或因果对照。
- 综述或设计研究：分别记录文献筛选与综合方法，或设计约束、迭代过程和评价证据。章节安排遵从目标专业及导师要求。

## 工具与交付

先确认用户选用的 Word、LaTeX、Origin、MATLAB、Python 或其他工具及本机可用性，现有模板、语言和格式优先。内嵌技能是说明与工具快照，不保证安装或运行。软件不可用时继续可完成的文本、结构和来源核查，记录不能完成的渲染、图形回开或可编辑性检查，避免宣称完整验收。若用户要求交付特定格式，该格式仍是未完成项。

使用已有工作区时，先识别当前文件及人工修改，采用索引或增量记录，未经授权不移动、覆盖或批量删除。新建工作区按需求创建必要目录。公开分享前独立核对许可证、隐私和可分发范围，课题组版包含不可公开分发或尚未核清授权的内嵌素材。
