# Word、公式与排版

学校规范及用户模板优先。先识别页面、页眉页脚、页码、标题层级、正文、目录、图表题、参考文献和附录的要求，再用 Word 样式、编号、题注及交叉引用实现。避免将历史项目中的字体字号推广为所有学校的要求。

编辑前保存原件或可恢复版本，记录真实文件及修改范围。对现有 DOCX 先统计并检查公式对象、MathType/OLE、OMML、引用域和关系文件。修改含对象段落时保护节点顺序、字段和编号制表位，不整体替换导致对象丢失。更新具体数字应定位表格单元格或上下文，禁止全局数字替换误改文献、年份和公式编号。

新建公式优先采用用户要求的可编辑格式。Markdown 中公式需转换为规范数学表达，生成 Word 原生 OMML 后检查行内变量、公式解释、表头、编号和页面表现。确需 MathType 则按用户明确需求保留原文件并验证实际 OLE 对象及可编辑性。不能将纯文本、图片或转换过程提示冒充可编辑公式。

检查目录、标题编号、分页、孤行、图表位置、图题、三线表、公式居中与编号、长公式换行、引用域及参考文献。分别记录正文引用域数、唯一文献数和文末条目数，不能要求相等。结构校验之外须渲染页面并检查实际 Word/WPS 的相关页面。缺工具、缺模板或未看页面时明确未验证范围。
