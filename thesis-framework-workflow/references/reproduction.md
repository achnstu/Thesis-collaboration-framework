# 模板与示例的复现方式

## 使用次序

需要搭建工作目录时，先按 [工作区架构](workspace-architecture.md) 识别已有文件、目录职责和数据来源。目录树是可裁剪的示例，不要求迁移现有项目。

1. 复制所需模板到用户指定的工作目录或项目已有规划目录，保留原始模板。局部任务只填写相关字段，不创建无关文件。
2. 将学校规定、导师意见、当前文稿、数据、代码和结果按实际版本登记。来源优先使用用户指定版本和可查原始证据，不以文件名“最终版”或时间最新代替核验。
3. 用规划表建立章节—论点—证据—图表映射，逐项填写状态、负责人和缺口。若改动一项结果，沿数据、图表、正文、摘要和结论追踪影响。
4. 为需要制作或复核的每一幅图复制图表记录模板。先核对科学问题、样本、聚合顺序、单位与可比性，再选软件和形式。方法、数据范围或样本变动后重新核对。
5. 写作时将每句结论定位到证据或经核验文献。表达证据的比较对象、范围及限制，保留对相反结果或失败的记录。未核实内容作为缺口，不写成结论。
6. 根据目标格式用排版表逐项核对，分别记录结构、渲染、实际 Word/WPS 和对象可编辑性。完成后保存结果、依赖、版本、原始输入位置、验收记录与未完成项。

## 已附带的素材

- `assets/templates/`：论证规划、图表记录、排版验收模板，可复制为项目工作底稿。
- `examples/sample-results.csv`：12 行虚构数据，重复和场景字段独立，适合手算或用统计软件验证。
- `examples/worked-example.md`：从问题、聚合、图表设计、正文至检查的完整示例，包含预期值。
- `embedded/editaplot/`：可按其许可使用的 Origin 技能与参考素材。运行依赖另见[内嵌技能清单](embedded-skills.md)。
- `embedded/nature-figure/assets/`：源技能自带的参考素材，使用前核对其来源、许可和适用范围，不把第三方图像或数字当作论文研究数据。

## 复现边界

模拟案例只验证逻辑与数值，不自动生成正式图或 Word。软件版本、字体、操作系统、学校模板和 Origin/Word 的可用性因机器而异。OPJU、MathType 和原生引用域等能力需在目标环境实际测试。项目专用历史脚本可能引用旧路径，应先检查输入与输出，禁止盲目覆盖现有成果。

移植整个技能包后，先从根入口打开相对路径。检查嵌入技能引用的运行时和第三方工具，不能因文件存在就宣称运行成功。正式运行时记录数据哈希、参数、依赖版本、软件输出及验收结果。
