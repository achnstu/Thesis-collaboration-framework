# 写作执行与反向自检

写作、改写、翻译和文字审查按任务含义自动启用本模块，覆盖论文、题注、释义、回复、研究说明及 README。保真、自然和最小必要修改通用，结构、语态与格式按文体和作者要求适配。具体写法读 [写作与证据](writing.md) 的相关小节，不为一次局部修改加载全部资料。

## 写前固定依据

1. **定版本与边界。** 接手时先读当前要求、项目规则、作者确认的稿件及目标部分相邻内容，用实际稿件定位。历史稿、前任 AI 的摘要和交接记录仅作线索，不能覆盖作者手改或替代证据。有多个版本时优先用作者指定稿，不凭文件名或修改时间认定终稿。
2. **定本节写法。** 从[各部分起草路线](writing.md#从研究问题到各部分写法)选择本节职责，先确定它要回答的问题、段落顺序和应留到别处的内容，再写句子。涉及研究论证的实质起草与改写分清主比较、解释及适用范围，写作动作须服务于本研究证据。以作者认可的段落校准表达，准确自然的原句可以保留。
3. **锁定事实和术语。** 把核心主张对应到实际证据，保留比较对象、条件、指标口径、关键数值、单位及结论强度。起草前按独立阅读范围决定缩写：摘要与正文分别检查；默认只出现一次的术语用全称，需要反复使用的术语首次写全称和缩写、后文统一用缩写。已定义的符号沿用现稿的完整记号和样式。作者有明确约定时以作者约定为准。

只读目标部分和必要材料，不要求新建任务记录，也不要求用户复述前情。现行材料能确定的自主推进。仅当版本冲突或证据缺口会改变关键主张时，提出一个具体问题或明确交付已能完成的候选部分，不猜填。切换语言、章节、稿件或恢复压缩后的会话时重新确认依据。需要换人续写时，给出当前稿件路径与位置、已完成与未完成项、关键证据位置及下一步；已有交接位置就复用，不另建台账。

参考引导的起草、实质改写及逐段或逐句对照，执行 [参考引导写作与论证重构](writing.md#参考引导写作与论证重构)，直接读取该节链接的内嵌 Followwriting 及必要方法。落笔前说明本段职责、拟采用的动作及本研究证据，篇幅较大的改写复用现有提纲保存关键决定。成稿后检查实际效果，不用补写一张计划表证明事前思考。具体任务可复用 [写作提示词](../assets/templates/writing-prompts.md)，句子对照与本节检查合并执行。

## 一名子代理集中复查

本技能包含自动文字复查授权。完整段落、章节或一批题名等文字完成后，默认自主派发 **一名只读子代理**，承担下一节的这一轮反向检查，无需每次向用户确认。主代理不先做同样的全文审查再让它重做。同批文字集中送查，不按句、按段各建一名代理。

- 只提供目标与文体、原文或已确认事实、完整待交付文字、当前作者约定、本文件及必要指南小节。指定可读文件和位置，不转发全部会话或工程历史，不暗示预设错误。
- 复查者先从实际待交付文字恢复本段或本节的问题、比较和判断，再对照原文、证据及写作记录按下表检查。现稿读不出的关系不能由写作说明替它补齐。返回具体问题的位置、对应规则及必要的局部建议，不打分、不强找问题、不直接改共享稿件，不再派发代理或创建新对话。
- 送查的是准备交付的完整文字，不是提纲或已舍弃的候选稿。收到复查结果并处理前，不将送查稿或另一版标为完成，也不写回正式稿。复查不可用时改由主代理做同一轮检查，不跳过检查。
- 主代理按原文和证据判断意见，落实合理修改，再复核改动处及关联项；若压缩或重排影响首次定义、段落主线或篇幅，一并复核。改变事实或超出授权的建议不采纳，默认不再派第二名复查者。
- 错别字、个别标点等微调，任务本身仅为复查，用户禁止代理，或平台不提供子代理时，由当前执行者完成这一轮检查，不反复等待或升级审批。

## 写后反向检查：从实际成稿出发

检查本轮全部新增和修改文字，包括题名、题注、表注及公式释义。以下各项可在一次通读中完成，不适用项略过，不要求向用户展示检查表。长文按节处理，最后核对本轮跨节一致性，未改部分只看必要上下文。

| 检查项 | 从成稿反查什么 | 发现问题后怎样处理 |
|---|---|---|
| 事实保真 | 实质主张能否对应原文或证据，原文有无独立信息被遗漏 | 撤回无依据新增，恢复条件、对象、数值、单位、否定、归因及确定程度。纯润色保留原主张，事实疑点在正文外说明，不静默猜改 |
| 缩写与命名 | 当前阅读范围的首次定义、后续简称、指标名称和作者现稿 | 沿用已确认名称，不因换章重定义或用近义词更换指标。只有局部材料时不声称已查全文首次定义 |
| 公式与释义 | 变量→完整符号，完整符号→含义，同看字体、正斜体、粗细、上下标、量纲和新符号释义 | 同定义沿用同符号及数学样式，防止插入或表头加粗带来样式漂移。区分向量与标量、实际值与指令、均值、估计量和时间点，不误合并。样式核对并入本轮检查，不另加一轮。不确定冲突具体报告，不猜替换 |
| 论证与段落 | 仅从成稿能否看清本段问题、主比较与解释、条件、指标、观察和推论，以及前后承接 | 在读者首次需要的位置补齐已有条件，修复断点。同一问题的发现、数字和解释连贯成段，不把不同设计拼成同一排名。拆句不机械拆段，不补造原因、删除取舍或升级代理指标 |
| 参考借鉴与对照 | 实际改写是否体现所称写作动作，参考版本与页段是否真实，本研究证据与写法来源是否分开 | 保留真实有效的借鉴，移除未落实或虚构的对应，不把参考结果迁为本研究结论。要求逐句对照时覆盖每句及真实拆并关系，保留句和研究特有句可无锚点，不能用通用短语证明一一对应 |
| 语言与冗余 | 作者语言约定、自然科研术语、题名、摘要篇幅、单位提示、工程旁白和收尾 | 摘要中文不超过300字，英文不超过150词，明确另定的要求及计数口径按[摘要规则](writing.md#摘要形成一条完整而有取舍的信息链)处理，合并本轮检查计数一次。不生造直译名词，不把文件操作写入正文。题名不堆已有表头和图例中的设置，不重复单位提示或已定义量。保留数值单位和必要定义，不按词语黑名单强改 |
| 交付与范围 | 用户要文字、对照、审查意见还是文件修改，实际处理了哪些位置 | 给对应成果，不擅自写回。内容、对象和页面分别按实际范围报告，未查不报通过，必要疑点简短说明 |

英文的短句、自然被动、第一人称、where 释义及标点按当前作者约定核对，保留文献作者归属。中文按其文体处理，不机械套英文句式。必要证据边界写在相关判断中，不在各段反复追加免责声明。

**默认一轮定向检查，修正后只复查受影响部分。** 原文已足以支持改写时，不逐句重新检索文献或读取原始数据。输入未变的已确认定义和结果直接复用，不重跑无关实验、全量哈希或页面渲染。检查未完成不能标为已验收，资料缺失时可以交付注明具体待核点的候选文字，不因无关检查拖住任务。

## 交付方式

通常给最终文字和必要说明。用户只要正文时只交正文，检查仍执行，不附自检口号、评分或长报告。已有修订记录时集中写“位置—具体问题—处理—检查范围”，无需另建报告。用户要求说明落实情况时，给实际对照及未查范围。

例如，“表题删去表头已交代的预算清单，核对后仍能区分比较对象”，比“图表题名已去 AI 味”更可核对。没有问题就保留原句，不为证明检查发生而制造修改。退回与保留的例子见 [对照示例](writing-examples.md#反向自检的退回示例)。

## 接入现有项目

首次用于一个项目时，主动提醒作者：长期使用建议把下方短规则写入现有标准 `AGENTS.md`，列为项目内高优先级约定，并填写实际技能路径。已经配置或作者已作决定时不重复提醒，不把配置作为本次写作前提。有维护该文件的授权时可直接更新，否则只给可复制文字，不自动修改全局配置。

```markdown
## 高优先级写作与模块执行约定

- 填写本项目实际论文框架 SKILL.md 路径。各任务按含义选择模块，只加载必要材料，其他同名旧副本不并行作为规则源。
- 已确认的作者语言、缩写、完整符号及样式约定优先于工具技能的通用默认，当前用户要求、作者确认稿及适用上级指令仍优先。
- 文字任务必读 references/writing-review.md 及相关写法。允许自动派发一名只读子代理集中复查同批文字，主代理落实后仅局部复核，不递归派发、不创建新对话。微调、纯复查、用户禁止代理或平台不支持时由执行者自检。
- 各模块在产出后做一轮定向检查，复用有效核验，不加无关扫描或重复报告。只要文字就只交文字，不擅自改文件。
- 已授权的并行任务明确依赖、输入版本和独立输出，每个共享文件由唯一负责人写入，整合时检查接口和一致性。
```

这段规则规定项目内的调用与检查，不改变宿主指令层级。不同客户端是否自动加载 AGENTS.md 需按实际机制确认，未自动加载时直接提供技能入口和本文件。包校验只证明可机械检查的事项，实际语言效果仍需看成稿。
