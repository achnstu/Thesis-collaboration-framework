## 发布流程

1. 明确目标仓库、许可证及作者授权，逐项核验内嵌代码、字体、示例、图片和其他素材的来源与许可。对未确定许可的内容保留在本地，采用经授权的替代品或自行编写的通用说明。
2. 审查 Git 将追踪的真实文件内容及二进制素材，检查个人路径、敏感信息、真实数据及引用中的旧地址。保留必要署名和许可证。按实际文件调整公开版配置，不能通过强制添加所有被忽略文件绕过审查。
3. 检查所有相对链接、许可文件、Git 忽略项、跨技能引用和运行依赖。在干净环境基于实际拟发布文件验证技能入口、示例、可选工具与文档。对需要 Origin、Word 或网络的步骤分别记录真实测试范围。
4. 提交前遵循项目的 secrets 检查和 staged diff 审查。只有用户授权时才提交或推送。
