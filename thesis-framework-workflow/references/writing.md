# 写作与证据

## 从框架到章节

1. 写一句研究问题、一组具体贡献以及各贡献对应的证据。比较对象、实验条件和证据边界需可追溯。
2. 建立“章—节—问题—方法—材料—图表—预期结论—缺口”映射。每章承担独立功能，研究章节通常有引言、方法、实验、结果和小结，结构按学科与导师要求调整。
3. 将多个章节共用的概念、理论、材料或研究方法放在合适位置，避免重复。实验研究可集中介绍模型、评价指标和实验协议，算法改进研究可先建立基线再说明增量，其他学科按研究设计组织，不强制基线或统一实验协议。
4. 小论文是素材，不是直接复制模板。逐段归位至大论文框架，核对新旧实验口径、图号、公式与引用。文献综述比较多条研究路线，以文献证据提出研究缺口，避免由单篇论文支配全文。
5. 每段有明确作用，按需要组织研究条件、比较对象、证据、解释和必要限制。不同段落可承担定义、方法推导、文献综述或讨论，不机械套用同一种顺序。解释须符合机制和证据，不将相关性写成因果。具体句式及防御性表达处理见 [中文学术表达与论证](chinese-academic-style.md)。

## 可追溯性

- 记录源文件、版本或哈希、工作表/字段、筛选范围、实验设置、计算脚本、单位和聚合顺序。分别标记事实、推断、待核实。
- 区分单个样本、重复实验、群体统计以及均值、标准差、区间的定义。统计方法由设计和数据决定，不把某种统计量作为所有论文的强制条件。
- 按源代码、配置及真实运行记录校对公式、变量、观测与动作定义，历史运行版本未知时明确限定。符号字母、下标、单位、采样间隔和正负号全文统一。
- 文献逐条核对作者、年份、题名、出处、DOI 和原文支持，不能凭搜索摘要编造结论。新文献、原始引用域及文末条目分别追踪。
- 中文学术表述准确自然，避免空话、重复及无证据拔高。保留作者表达、限定和信息，不承诺检测结果。标点遵循当前作者、学校和项目的要求。

## 交付检查

章节之间不自相矛盾。展示数据前先交代理解图表所需的来源和划分，再在合适位置说明实验设置。图表有引出、解读和落位，正文不照搬图内标注。摘要和结论逐项追溯至结果，不外推到未验证场景。保留版本与修改记录，未完成检查如实报告。
