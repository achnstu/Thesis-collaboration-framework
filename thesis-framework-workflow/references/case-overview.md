# 匿名论文工作流案例

本案例仅保留可迁移方法，不包含原作者的工作代号、会话 ID、实验目录或个人路径。无需访问原历史文件即可理解。

- [框架、工作区与多任务协调](case-framework.md)：把章节问题与共同证据、职责和交接关联。
- [数据口径与科研作图](case-data-figures.md)：逐轨迹核验、统计层级、单位和原生工程验收。
- [写作、公式与排版](case-writing-layout.md)：组织论证、核查引用、保护可编辑对象与字段。

示例中的算法名是领域术语，数值和章序仅用于解释方法，不代表使用者的研究结论。真实论文应以当前作者输入、学校规范及原始证据确定。后续 [瀑布图示例](origin-perspective-waterfall.md) 使用包内合成数据，所有必要操作与参考 PNG 均独立可读。
