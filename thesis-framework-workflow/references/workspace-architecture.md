# 论文工作区、阶段与交接

用于搭建或理解可追溯的论文项目。目录与阶段可按学科和任务裁剪，局部改文或改图不要求重建工作区。现有结构、用户指定位置、作者手改及当前规则优先。

## 开始前

确认当前任务、主稿、学校或期刊规范、研究材料、交付格式和可写范围。已有目录先建索引，不因命名不同就复制、移动或重建。不凭“最终版”文件名或时间最新认定主稿，入口记录实际版本及确认依据。

新建或整理目录时按真实工作创建必要位置，迁移前明确来源、目标和冲突处理。保护原始资料及历史版本，路径失效或资料未取得时记录缺口，不虚构来源。删除仍遵循当前项目规则。

## 目录职责

| 位置示例 | 保存的内容 |
|---|---|
| 工作区入口 | 当前主稿、规范、进度、来源索引和待办，参考 [入口模板](../assets/templates/workspace-entry.md) |
| 规范与已有成果 | 模板、导师意见、可用论文及版本，按许可保存或记录位置 |
| 稿件 | 当前稿、按章底稿、必要的版本快照与修改说明 |
| 数据与证据 | 来源和哈希、只读原始材料或索引、派生表、处理参数和代码 |
| 图表 | 图表计划、数据来源、绘图代码、可编辑工程、输出及验收 |
| 文献 | 元数据、原文位置、论点支持记录与引用库，详见 [文献工作流](literature.md) |
| 写作管理 | 章节—证据映射、符号和公式、修改核验、按需协作台账 |
| 交付 | 用户指定的阶段成果、输入输出版本和未决事项 |

名称、数字前缀与子目录由团队决定，不要求复制整套示例。已有正式实验归档优先用索引引用，不整库搬进论文目录。没有数据图、数值或实验的研究，按史料、访谈、设计材料等实际证据组织。

图表可按章分别保存“数据及来源、代码、原生工程、输出、验收”，也可沿用工程与输出同目录的既有习惯，不强制生成所有格式。每幅图能追到输入、筛选、统计、版本和生成方式即可。示意图记录内容来源与可编辑原件。

## 文件命名与版本

- 稳定材料 ID 与正式图号分开，例如 FIG-D 与图 3-2。编号变更同步索引、正文、图题、表格和相关代码，不凭文件名猜内容。
- 文件名写明主题、版本或日期，入口另外记录哪个版本正在采用以及确认依据。
- 主稿和原生工程修改前保留可恢复版本，核实备份存在且可读。写入前检查作者是否又有新改动，不用旧脚本覆盖较新的手工工程。
- 数据索引记录源位置或持久标识、版本/哈希、表及字段、范围、筛选、统计定义和权限。派生材料保留参数及脚本，原始输入不被改写。
- 章节与材料按 [规划模板](../assets/templates/thesis-planning.md) 关联，图表按 [图表记录](../assets/templates/figure-record.md) 追溯。无需为没有实际内容的工作创建空目录。

## 阶段实施与交接

按依赖推进，证据确定后图文可交错准备。阶段表是工作参考，不要求作者逐项填表或批准，局部任务只检查受影响的链条。

| 阶段 | 主要输入与工作 | 交付和进入下一步的依据 |
|---|---|---|
| 资料接收 | 目标、当前稿、规范、材料与版本 | 可定位的入口和来源，未取得项明确标记 |
| 研究定位 | 问题、方法、贡献、对照和导师意见 | 论点—证据映射，已完成与计划分开 |
| 章节规划 | 全篇主线、章节职责和前后承接 | 章节素材、图表与公式落位，缺证据项可见 |
| 数据与图表 | 来源、样本、字段、聚合、单位及失败信息 | 可复算派生表、图表工程、代码与相关检查 |
| 逐章写作 | 问题、方法、结果、讨论与文献 | 结论有证据，图文、符号和引用一致 |
| 文档装配 | 授权内容、目标文稿、对象及样式 | 可编辑候选，公式、媒体、字段和编号受保护 |
| 综合验收 | 核心计算、来源、结构与实际页面 | 区分自动检查、目视检查及未完成项 |
| 阶段交付 | 当前成果、版本、依赖和待办 | 文件存在可读，交接对象和下一步明确 |

缺证据、版本冲突或条件不可比时，标记影响位置，独立部分继续。已有有效核验在输入和条件未变时复用，不将未完成写成通过。验收深度与风险相称，作者反馈通过 [共同审阅](multi-chat-collaboration.md#作者与-ai-共同审阅) 结合真实成果处理。

## 变更与验收

证据、统计、编号或章节改变时，沿“来源 → 派生材料 → 图表 → 正文 → 摘要与结论”核查影响。记录原因、版本、范围、核验和未决项，不把通知发出当作修改完成。多人或多对话协作的方法见 [协作指南](multi-chat-collaboration.md)。

| 核验对象 | 重点 |
|---|---|
| 工作区与证据 | 入口当前、来源可定位、样本及统计层级清楚，缺测与失败未丢失 |
| 图文与公式 | 材料 ID 与正式编号对应，单位、术语、符号一致，图形实际回开 |
| 文献与格式 | 引用句有原文支持，引用域与条目对应，格式服从目标规范 |
| 文件与页面 | 结构、渲染、实际软件显示及可编辑性分别记录，未查看不报通过 |
| 交接 | 使用 [交接模板](../assets/templates/handoff.md) 记录真实输入输出、版本、检查、限制和下一负责人 |

工作区服务于追溯和协作，不要求每个任务复制所有资料。作者已在使用的结构优先沿用，索引只连接当前需要的内容。
